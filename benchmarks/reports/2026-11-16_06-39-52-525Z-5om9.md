## Method

The benchmark laboratory is independent of MSF Fusion packages. Each scenario is executed with pinned competitor versions, production builds where applicable, warm-up runs, and repeated samples. Raw samples are preserved in the JSON file. Medians, P95 values, and coefficients of variation are reported; no composite performance score is calculated.

See `benchmarks/methodology.md` for exclusions, fairness rules, and known limitations.

### How to read the statistics

- **Median**: the 50th percentile of the raw samples (linear interpolation, R-7).
- **P95**: the 95th percentile of the raw samples; higher values mean worse tail latency.
- **CV**: coefficient of variation (`stddev / mean`, sample standard deviation). Values above roughly 10% indicate an unstable measurement on this machine.
- **MAD**: median absolute deviation from the median, a robust spread measure.
- **Ops/s**: `1 / median`, reported for convenience only and never used as a ranking score.

## Limitations and exclusions

- Milestone 0 baseline only. MSF Fusion is not implemented, so this run contains no MSF Fusion measurements.
- All result values are machine- and time-specific. Raw samples are preserved in the JSON file.
- Graph construction is performed outside the timed region; warm-up runs are discarded.
- Each sample uses a fresh graph and disposes it afterwards where the primitive exposes disposal.
- Solid runs through its client runtime exported by the package (solid-js/dist/solid.js) so computed invalidation is live. Solid effect scenarios are skipped because effects require a render flush.
- Vue effects are synchronous in the standalone @vue/reactivity package; Vue's default scheduler batching is not part of this matrix.
- Angular is excluded from microbenchmarks: its signal API is not designed as a standalone package and effects require an injector/DI context.
- React has no comparable standalone signal primitive; React component rendering is measured in the DOM suite instead.
- No MSF Fusion numbers are present in this baseline.
- Each application renders the same 1,000-row markup on every request; no data fetching or I/O is included.
- SSR builds use Vite's SSR mode and each framework's official production renderer.
- React uses react-dom/server renderToString; Solid uses renderToString; Svelte uses svelte/server; Vue uses vue/server-renderer.
- Next.js, Angular SSR, and Qwik are not included because their server stacks add routing, bundling, and transport layers that are not functionally equivalent to a single render call.
- Hydration and streaming SSR are not measured in Milestone 0.
- SSR build time is recorded separately and is not part of the render latency samples.
- The same functional application (empty table plus imperative benchmark API) is built for every framework.
- One untimed warm-up build runs before three measured builds; each build starts from an empty dist directory.
- Build time includes Vite's in-process config loading and transform pipeline, but not package installation or TypeScript checking.
- React has no compiler plugin in this baseline (React Compiler intentionally disabled).
- Bundle sizes include framework runtime and benchmark harness code; they are not hello-world sizes.
- Angular and Next.js builds are not included in this baseline; see benchmarks/methodology.md for the reason.
- All applications expose the same imperative benchmark contract and render the same table markup.
- frameMs includes two requestAnimationFrame waits after the state update, so it has a fixed frame-scheduling floor of roughly 16-34 ms depending on refresh timing.
- syncMs measures only work completed before control returns to the benchmark harness; asynchronous commits are visible in frameMs but not syncMs.
- Preparation renders are outside the timed region. Warm-up runs are discarded.
- No CPU or network throttling is applied. Frame latency is expected to vary on shared desktop hardware.
- Memory values are CDP garbage-collected heap sizes after create-10000 and clear; they are not proof of absence of leaks.
- React fixtures use production React without React Compiler. Angular and Next.js are not part of the DOM baseline in Milestone 0.
- Results describe one machine and one point in time. They are not a universal ranking.
- Angular, Next.js, Qwik, streaming SSR, hydration, and long-running memory-leak scenarios are not yet measured.
