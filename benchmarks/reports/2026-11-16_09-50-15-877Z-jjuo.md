## Method

Library-specific primitives are compared, not whole frameworks. Read the semantic notes in the JSON before interpreting these numbers. Competitors were measured as pinned packages; MSF Fusion measurements use the in-repo developer-preview runtime.

See `benchmarks/methodology.md` for exclusions, fairness rules, and known limitations.

### How to read the statistics

- **Median**: the 50th percentile of the raw samples (linear interpolation, R-7).
- **P95**: the 95th percentile of the raw samples; higher values mean worse tail latency.
- **CV**: coefficient of variation (`stddev / mean`, sample standard deviation). Values above roughly 10% indicate an unstable measurement on this machine.
- **MAD**: median absolute deviation from the median, a robust spread measure.
- **Ops/s**: `1 / median`, reported for convenience only and never used as a ranking score.

## Limitations and exclusions

- Baseline benchmark run. When MSF runtime preview fixtures are included, treat them as informational developer-preview measurements (not superiority claims).
- All result values are machine- and time-specific. Raw samples are preserved in the JSON file.
- All applications expose the same imperative benchmark contract and render the same table markup.
- frameMs includes two requestAnimationFrame waits after the state update, so it has a fixed frame-scheduling floor of roughly 16-34 ms depending on refresh timing.
- syncMs measures only work completed before control returns to the benchmark harness; asynchronous commits are visible in frameMs but not syncMs.
- Preparation renders are outside the timed region. Warm-up runs are discarded.
- No CPU or network throttling is applied. Frame latency is expected to vary on shared desktop hardware.
- Memory values are CDP garbage-collected heap sizes after create-10000 and clear; they are not proof of absence of leaks.
- React fixtures use production React without React Compiler. Angular and Next.js are not part of the DOM baseline in Milestone 0.
- Results describe one machine and one point in time. They are not a universal ranking.
- Angular, Next.js, Qwik, streaming SSR, hydration, and long-running memory-leak scenarios are not yet measured.

pnpm install --frozen-lockfile

pnpm bench:ssr
